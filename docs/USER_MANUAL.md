# 사용 설명서 (담당자용)

동아리 생일 축하 메시지를 개인톡으로 일괄 발송하는 도구.

## 준비물

- Windows 10/11
- 카카오톡 PC 버전 (로그인된 상태)
- 회원 명단 CSV 또는 원본 `members.json`

## 처음 설치 (한 번만)

### 1. 저장소 받기
```
git clone https://github.com/TurnaboutHero/kakao-sender-v2.git
cd kakao-sender-v2
```

### 2. uv 설치
PowerShell 에서:
```
irm https://astral.sh/uv/install.ps1 | iex
```

### 3. 의존성 설치
```
uv sync
```

## 첫 사용 — 명단과 매핑 세팅

### 3-1. 원본 `members.json` 이 있다면
```
uv run python scripts/migrate.py path/to/members.json
```
→ `data/members.csv` 자동 생성.

### 3-2. 처음부터 만든다면
```
uv run python -m kakao_sender
```
"👥 명단" 탭에서 ➕ 추가로 한 명씩, 또는 "📂 legacy .json 불러오기" 로 import.

### 3-3. 매핑 (가장 중요)

**"🔗 매핑" 탭** 이 핵심. 각 회원의 **내 카톡에 저장된 이름** 을 입력한다.

- 공식명 "회원나" / 내 카톡 저장명 "별칭나" → `별칭나` 입력
- "동명 자동 채우기" 로 빈 칸에 공식명을 우선 넣고 다른 건만 수정하는 것도 방법
- 입력한 건 **💾 매핑 저장** 눌러야 `data/mapping.json` 에 저장됨
- 미매핑 칸은 발송 대상에서 **자동 스킵** (경고만 나옴)

## 매주 발송 루틴

1. **카카오톡 PC 를 열어 "친구 탭" 에 위치** (중요 — 채팅 탭이면 안 됨)
2. `uv run python -m kakao_sender`
3. "📨 발송" 탭
4. ✉️ 메시지 입력 (예: "생일 축하해요 🎂")
   - "문구 변주 사용" 체크 시 4가지 기본 문구 중 랜덤 (카톡 스팸 필터 회피)
5. 🖼️ 이미지 첨부 (선택)
6. **🚫 생일자 제외 설정** — **반드시 생일자 본인을 체크**. 체크된 사람은 발송 대상에서 빠짐
7. **▶ 발송 시작** 클릭
8. 확인창에서 "예"
9. **카카오톡 창 건드리지 말고** 기다리기 — 160명 기준 13~15분
10. 완료 후 실패자 있으면 **↻ 실패자만 재시도**

## 발송 중 주의

- 카카오톡 창에 **절대 마우스/키보드 입력 금지** (자동화가 꼬임)
- 창 크기 바꾸거나 다른 프로그램 가져오지 마세요
- 종료하려면 "■ 중지" — 현재 한 건 끝내고 멈춤 (중간에 카톡 강제 종료 금지)

## 실패 대처

### "대상 검증 실패: 창 제목=X, 기대=Y"
내가 저장한 이름과 실제로 열린 채팅창의 상대 이름이 다름.
→ 해당 회원을 매핑 탭에서 올바른 이름으로 수정.
→ 실패자 재시도.

### "창을 찾을 수 없음: '카카오톡'"
카카오톡 PC 가 꺼져있거나 창 제목이 다름.
→ 카카오톡 실행 후 재시도.

### "포커스 실패"
다른 프로그램이 포그라운드를 잡고 있음.
→ 다른 창 모두 최소화하고 재시도.

### 카톡 스팸 차단 (24시간~며칠 발송 제한)
150명 이상 연속 발송 시 드물게 발생.
→ 발송 시간을 낮 시간대로 옮기기, 발송 간격 더 늘리기 (config.py 의 `between_send_min/max` 조정).

## 담당자 교체 시

- **공용 명단 (`data/members.csv`)** 은 그대로 인수인계 (Google Drive / 단톡 파일 등)
- **매핑 (`data/mapping.json`)** 은 담당자마다 다름 → 새 담당자가 "🔗 매핑" 탭에서 **자기 카톡 기준으로 재작성**
  - "동명 자동 채우기" 로 70~80% 는 자동 완료, 나머지만 수동
  - 5~10분 작업

## 로그 확인

- 발송 중 실시간 로그: "📋 로그" 탭
- 파일 로그: `logs/YYYY-MM-DD.log` (30일 자동 보관)
